# Startify Sprint

Рабочий MVP для **AI Startify Global Growth Challenge**, направление 2 — **Startup Creation & Activation**.

Идея: не больше регистраций, а больше состоявшихся стартапов. Школьная команда проходит 7-дневный спринт, ведёт рабочую тетрадь, получает помощь наставника, публикует паспорт в AI Startify и получает зачёт только после ручной проверки организатора.

## Быстрый старт

Требуется Node.js **22.13+** (используется встроенный `node:sqlite`).

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`.

Демо-вход включён по умолчанию вне production. В интерфейсе выберите **«Посмотреть демо-команду»** или **«Демо-организатор»**. Демо-данные помечены и не являются статистикой всей платформы AI Startify.

## Что работает

- обзор, витрина подтверждённых проектов, лига школ и стран;
- создание команды, nickname, код приглашения, одноразовый ключ восстановления;
- 5 этапов: идея, проверка проблемы, решение/бизнес-модель, питч, публикация;
- рабочая тетрадь с сохранением, экспортом и последовательными контрольными точками;
- наставник: следующий шаг, проверка, каркас, питч; RU/EN;
- явное применение AI-черновика, без автоматической публикации;
- отправка ссылки `https://aistartify.com/startup/<id>`;
- ручная проверка: подтвердить или вернуть с комментарием;
- блокировка заметок на время проверки и после зачёта;
- рейтинг по подтверждённым публикациям, один паспорт — один зачёт;
- ссылка-вызов другой школе с атрибуцией и счётчиком открытий приглашения;
- **кабинет координатора школы**: прогресс своих команд, список «кому помочь», напоминания, статистика приглашений, ротация ключа;
- **внутренние напоминания** командам с отметкой о прочтении и защитой от спама;
- **сезоны спринта**: несколько когорт со своими кодами, рейтингом и витриной;
- **безопасный сброс демо** без потери реальных пилотных данных;
- панель организатора: воронка, очередь, CSV, LLM health, активационные события, ключи координаторов, управление сезонами;
- стратегия роста с интерактивной воронкой, бюджетом, roadmap и комплектом учителя;
- удаление данных собственной пилотной команды.

## SmallThinker

По умолчанию LLM отключена: наставник возвращает **явно помеченные шаблоны**, а не фальшивые AI-ответы.

Для реального инференса запустите SmallThinker через llama.cpp или другой OpenAI-compatible сервер и задайте `.env`:

```env
LLM_ENABLED=true
LLM_BASE_URL=http://127.0.0.1:8080/v1
LLM_MODEL=smallthinker
LLM_RESPONSE_FORMAT=none
```

Проверка:

```bash
npm run llm:check
```

Полная инструкция: [docs/SMALLTHINKER.md](docs/SMALLTHINKER.md).

## Тесты и сборка

```bash
npm test          # unit, API, LLM-контракт, миграции БД и UI-тест на jsdom
npm run build     # production-сборка frontend
npm run test:e2e  # browser smoke, нужен запущенный dev-сервер и Chromium
```

`npm test` включает проверку миграции: база версии 0.2.0 и исходная схема MVP обновляются на месте, данные сохраняются, роль координатора добавляется пересборкой таблицы сессий. UI-тест монтирует реальные страницы, нажимает кнопки и проверяет, что уходят нужные запросы, — он работает без браузера.

Оба набора запускаются в GitHub Actions (`.github/workflows/ci.yml`): отдельными задачами идут unit+build и браузерный smoke.

Для e2e можно использовать системный Chromium:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm run test:e2e
```

## Production

```bash
npm run build
ORGANIZER_PASSWORD='long-random-secret' \
CHALLENGE_ACCESS_CODE='private-school-code' \
DEMO_MODE=false \
SEED_DEMO=false \
npm start
```

В production non-demo требует пароль организатора не короче 12 символов и приватный код челленджа. HTTPS-cookie включены по умолчанию; для локального HTTP-теста их можно отключить `COOKIE_SECURE=false`. За доверенным reverse proxy задайте `TRUST_PROXY=1` и `APP_ORIGIN`.

## Архитектура

- React + Vite;
- Express;
- SQLite через `node:sqlite`;
- один процесс: общий API и хранилище для ролей команды, координатора школы и организатора;
- миграции схемы применяются при открытии базы, без отдельного шага деплоя;
- серверный LLM-адаптер с JSON-валидацией, таймаутом, квотами и redaction-эвристикой.

## Честные ограничения MVP

- нет скрытого или выдуманного API AI Startify: ссылка проверяется человеком;
- нет автоматической синхронизации статусов с AI Startify и доказательства владения проектом;
- напоминания работают только внутри продукта: email и мессенджеров нет;
- интерфейс русскоязычный, выбор языка относится только к ответам наставника;
- демо-роли не предназначены для production;
- SmallThinker-веса не включены в репозиторий; реальный inference требует вашего сервера;
- это пилотная технология, а не юридически завершённый массовый сервис для детей.

## Сценарий демо для жюри

1. Открыть обзор и правило зачёта: только подтверждённые публикации.
2. Войти в демо-команду EduQuest.
3. Сохранить заметку и запросить «Следующий шаг» — ответ помечен «Шаблон · не AI».
4. Открыть **кабинет координатора школы**: список «кому помочь» и напоминание застрявшей команде.
5. Вернуться в команду — напоминание видно в инкубаторе, отметить прочитанным.
6. Показать очередь организатора: подтвердить учебную заявку с чек-листом или вернуть с комментарием.
7. Выдать ключ координатора реальной школы и открыть новый сезон — механика повторяема.
8. Показать витрину/лигу и ссылку-вызов, счётчик открытий приглашения.
9. Открыть «Стратегию роста»: воронка учитывает размер команды, бюджет и сценарии.
10. Показать `docs/SMALLTHINKER.md` и `npm run llm:check` как путь к реальному inference.

Сбросить демо перед показом можно кнопкой **«Сбросить демо»** в панели организатора: реальные пилотные команды и сезоны при этом сохраняются.
