# Startify Sprint

MVP для Symbat Hackathon, направление 2 — **Startup Creation & Activation**.

Startify Sprint — школьная лига стартап-спринтов поверх AI Startify. Продукт помогает довести команды от идеи до **подтверждённой публикации проекта**, а учителю и организатору — увидеть, где команды застревают, и помочь им дойти до результата.

## Что работает

- витрина челленджа и переключение между челленджами;
- вход команды по коду приглашения;
- кабинет команды с 5 контрольными точками и напоминаниями;
- переход в AI Startify;
- отправка ссылки на паспорт проекта;
- ручная проверка организатором: подтвердить / вернуть с комментарием;
- рейтинг школ и стран **в рамках выбранного челленджа**;
- кабинет учителя: только команды своей школы, список «кому помочь», напоминания;
- кабинет организатора: воронка, модерация, внимание к командам, аналитика приглашений;
- создание пилотного челленджа организатором;
- ссылка-вызов другой школе и учёт переходов/вступлений/публикаций по приглашениям;
- изолированный демо-сценарий и сброс демо без удаления пилотных данных;
- сохранение данных в SQLite и миграция старой схемы MVP.

## Важно об интеграции

MVP **не использует скрытый или выдуманный API AI Startify**.

Текущая интеграция:

1. команда открывает AI Startify по внешней ссылке;
2. публикует проект на стороне AI Startify;
3. копирует ссылку вида `https://aistartify.com/startup/<id>`;
4. организатор вручную проверяет ссылку и подтверждает зачёт.

Автоматическая проверка существования проекта, принадлежности проекта команде и синхронизация статусов — следующий этап после получения официального API или выгрузки от AI Startify.

## Запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Приложение доступно на `http://localhost:3000`.

Production-сборка:

```bash
npm run build
npm start
```

Тесты:

```bash
npm test
```

## Сценарий демо

1. Открыть главную страницу и показать правило зачёта: только подтверждённые публикации в текущем челлендже.
2. Нажать **Демо-команда**.
3. В кабинете команды увидеть напоминание, отметить этап и открыть AI Startify.
4. Отправить проект со ссылкой вида `https://aistartify.com/startup/demo-project`.
5. Нажать **Демо-организатор**.
6. Подтвердить заявку в очереди проверки.
7. Показать, что рейтинг и воронка текущего челленджа изменились.
8. Открыть вкладку **Внимание** и отправить напоминание застрявшей команде.
9. Нажать **Демо-учитель** и показать кабинет одной школы.
10. Скопировать ссылку-вызов другой школе.
11. При необходимости нажать **Сбросить демо** — пилотные челленджи не затрагиваются.

> Демо-данные помечены badge «Демо». Они не являются реальными школами, партнёрами или проектами AI Startify.

## Челленджи и изоляция данных

- Демо-челлендж имеет `is_demo = 1`; пилотные челленджи создаются с `is_demo = 0`.
- Команды, школы, заявки, рейтинг, воронка и аналитика скоупятся по выбранному челленджу.
- `POST /api/demo/reset` доступен организатору и восстанавливает только демо-набор.
- Старая база MVP мигрирует автоматически: добавляются поля демо-изоляции, активности, напоминаний и аналитики приглашений.

## Стек

- React + Vite;
- Express;
- SQLite через встроенный `node:sqlite` Node.js 22;
- один процесс, общий API и общее хранилище для ролей команды, учителя и организатора.

## Ограничения MVP

- демо-авторизация без паролей, не для production;
- ручная модерация ссылок;
- нет автоматической проверки доступности и владельца паспорта проекта;
- нет реальных персональных данных, платежей и подтверждённого API AI Startify;
- напоминания внутренние, без email/push;
- учительская демо-роль привязана к демо-школе; production-привязка учителей к школам — следующий этап.
