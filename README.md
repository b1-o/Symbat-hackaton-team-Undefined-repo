# Startify Sprint

MVP для Symbat Hackathon, направление 2 — **Startup Creation & Activation**.

Startify Sprint — школьная лига стартап-спринтов поверх AI Startify. Продукт помогает довести команды от идеи до **подтверждённой публикации проекта**, а организатору увидеть воронку и очередь проверки.

## Что работает

- витрина активного челленджа;
- вход команды по коду приглашения;
- кабинет команды с 5 контрольными точками;
- переход в AI Startify;
- отправка ссылки на паспорт проекта;
- ручная проверка организатором: подтвердить / вернуть с комментарием;
- рейтинг школ и стран по подтверждённым публикациям;
- ссылка-вызов другой школе;
- сохранение данных в SQLite;
- демо-роли без сбора реальных персональных данных школьников.

## Важно об интеграции

MVP **не использует скрытый или выдуманный API AI Startify**.

Текущая интеграция:

1. команда открывает AI Startify по внешней ссылке;
2. публикует проект на стороне AI Startify;
3. копирует ссылку вида `https://aistartify.com/startup/<id>`;
4. организатор вручную проверяет ссылку и подтверждает зачёт.

Автоматическая проверка существования проекта и синхронизация статусов — следующий этап после получения официального API или выгрузки от AI Startify.

## Запуск

```bash
npm install
npm run dev
```

Приложение доступно на `http://localhost:3000`.

Production-сборка:

```bash
npm run build
npm start
```

Тесты:

```bash
npm test
```

## Сценарий демо

1. Открыть главную страницу и показать правило зачёта: только подтверждённые публикации.
2. Нажать **Демо-команда**.
3. В кабинете команды отметить этап и открыть AI Startify.
4. Отправить проект со ссылкой вида `https://aistartify.com/startup/demo-project`.
5. Нажать **Демо-организатор**.
6. Подтвердить заявку в очереди проверки.
7. Показать, что рейтинг и воронка изменились.
8. Скопировать ссылку-вызов другой школе.

> Демо-данные помечены badge «Демо». Они не являются реальными школами, партнёрами или проектами AI Startify.

## Стек

- React + Vite;
- Express;
- SQLite через встроенный `node:sqlite` Node.js 22;
- один процесс, общий API и общее хранилище для ролей команды и организатора.

## Ограничения MVP

- демо-авторизация без паролей, не для production;
- ручная модерация ссылок;
- нет автоматической проверки доступности паспорта проекта;
- нет реальных персональных данных и платежей;
- один активный челлендж.
