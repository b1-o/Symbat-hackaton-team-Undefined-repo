# Подключение SmallThinker

Startify Sprint совместим с SmallThinker через **серверный OpenAI-compatible адаптер** (`server/llm.js`). Браузер не обращается к LLM напрямую и не получает API-ключ.

Рекомендуемый путь: **SmallThinker-4B-A0.6B-Instruct + llama.cpp**. Поддержка архитектуры SmallThinker добавлена в llama.cpp; для пилота важнее проверяемый локальный HTTP-контракт, чем конкретный UI вокруг модели.

## Что уже проверено в репозитории

- адаптер отправляет `POST {LLM_BASE_URL}/chat/completions`;
- ответ проходит строгую JSON-схему;
- ключ остаётся на сервере;
- удалённый endpoint допускается только по HTTPS, локальный — по HTTP на loopback;
- есть таймаут, лимит параллельных запросов, дневная квота команды;
- ошибка модели показывается пользователю и **не подменяется молча фальшивым AI-ответом**;
- при `LLM_ENABLED=false` наставник возвращает явно помеченные шаблоны.

В этой среде веса SmallThinker не запускались: для реального инференса нужен ваш сервер с моделью. Совместимость адаптера проверена тестами контракта; качество русских ответов конкретной модели нужно проверить на пилоте.

## 1. Запустите SmallThinker через llama.cpp

Используйте сборку llama.cpp с поддержкой SmallThinker. Пример с обычным GGUF-квантованием:

```bash
llama-server \
  -hf Tiiny/SmallThinker-4BA0.6B-Instruct-GGUF:Q4_K_S \
  --host 127.0.0.1 \
  --port 8080 \
  --alias smallthinker \
  -c 8192
```

Важно:

- берите обычный `.gguf`;
- файлы `.powerinfer.gguf` предназначены для PowerInfer, а не для этого пути;
- в новых версиях llama.cpp порт по умолчанию может отличаться, поэтому `--port 8080` задан явно;
- если chat template не подхватывается автоматически, добавьте `--jinja` или шаблон из карточки модели;
- `--alias smallthinker` должен совпадать с `LLM_MODEL`.

Проверка:

```bash
curl http://127.0.0.1:8080/v1/models
```

## 2. Настройте приложение

Скопируйте `.env.example` в `.env` и задайте:

```env
LLM_ENABLED=true
LLM_BASE_URL=http://127.0.0.1:8080/v1
LLM_MODEL=smallthinker
LLM_API_KEY=
LLM_TIMEOUT_MS=45000
LLM_MAX_TOKENS=900
LLM_RESPONSE_FORMAT=none
```

`LLM_RESPONSE_FORMAT=none` — самый переносимый режим: модель просится вернуть JSON, а приложение само извлекает и валидирует его. `json_object` или `json_schema` включайте только если ваш runtime точно поддерживает соответствующий `response_format`.

Проверьте один реальный вызов:

```bash
npm run llm:check
```

Затем перезапустите приложение:

```bash
npm run dev
```

В кабинете организатора есть кнопка **«Проверить подключение»**. Она отправляет один тестовый запрос и показывает задержку/токены, если сервер вернул usage.

## 3. Альтернативы

### Ollama

Если ваша версия Ollama поддерживает архитектуру SmallThinker, импортируйте обычный GGUF:

```text
FROM ./SmallThinker-4B-A0.6B-Instruct.Q4_K_S.gguf
```

```bash
ollama create smallthinker -f Modelfile
ollama serve
```

В `.env`:

```env
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_MODEL=smallthinker
```

Не предполагайте, что старый тег `smallthinker` в библиотеке Ollama обязательно является нужной 4B-A0.6B Instruct-моделью. Проверяйте `/v1/models` и фактический ответ.

### vLLM / Transformers

Адаптеру нужен OpenAI-compatible HTTP endpoint. vLLM подходит только если конкретная версия поддерживает SmallThinker. Оригинальный репозиторий SmallThinker указывает Transformers `4.53.3` и `trust_remote_code=True`; это не означает, что любой OpenAI-совместимый сервер автоматически поддерживает модель.

## Контракт ответа

Модель должна вернуть один JSON-объект:

```json
{
  "reply": "Короткий ответ наставника",
  "suggestions": ["Один практический совет"],
  "draft": "",
  "nextQuestion": "Один следующий вопрос"
}
```

Ограничения приложения: `reply` до 2400 символов, `suggestions` 1–4 пункта, `draft` до 3000 символов, `nextQuestion` до 600 символов. Лишние поля отклоняются. Черновик не сохраняется автоматически: команда должна нажать «Использовать черновик», проверить текст и сохранить заметки.

## Безопасность и эксплуатация

- Не отправляйте модели персональные данные детей. В приложении есть эвристика удаления email/телефонов, но это не полноценная анонимизация.
- Рабочая тетрадь и сообщение ученика считаются недоверенными данными; системная инструкция запрещает менять роль, раскрывать промпт и выдумывать интервью/метрики.
- У модели нет инструментов: она не может публиковать или подтверждать проект.
- Лимиты: 40 LLM-обращений на команду в сутки, максимум 2 одновременных upstream-вызова, таймаут по умолчанию 45 секунд.
- SmallThinker обучена преимущественно на английском. Перед массовым запуском проверьте русский/узбекский/киргизский/азербайджанский/грузинский сценарии с носителями языка.
- Для пилота начните с машины класса 8 GB RAM и измерьте задержку/память. Активные параметры MoE не равны полной памяти модели.

## Диагностика

| Симптом              | Что проверить                                                                         |
| -------------------- | ------------------------------------------------------------------------------------- |
| `llm_unavailable`    | запущен ли сервер, доступен ли loopback/HTTPS endpoint из процесса Node               |
| `llm_http_error` 404 | точный `LLM_MODEL`, путь `/v1`, наличие chat completions                              |
| `llm_invalid_json`   | `LLM_RESPONSE_FORMAT=none`, chat template, убедитесь, что вне JSON нет лишнего текста |
| `llm_truncated`      | увеличьте `LLM_MAX_TOKENS`, но оставайтесь в пределах контекста                       |
| `llm_timeout`        | уменьшите контекст/нагрузку или увеличьте таймаут после замера                        |
| `llm_busy`           | уже выполняются 2 запроса; повторите позже                                            |
| `llm_quota`          | команда исчерпала 40 обращений за сутки                                               |
