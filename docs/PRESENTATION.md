# Выступление без лишнего · Startify Sprint

**Главная история:** школьная проблема → команда проходит неделю по шагам → координатор помогает не остановиться → публикация подтверждена → школа зовёт следующую.

Не перечисляем все функции. Не начинаем с бюджета. Не заканчиваем списком того, чего ещё нет.

## 1. Кто что делает

- **Спикер** рассказывает историю и объясняет экран. Мышку не трогает.
- **Оператор** ведёт одно окно приложения по маршруту ниже. Не открывает дополнительные вкладки во время речи.
- **Остальные** отвечают на вопросы: один — продукт и SmallThinker, другой — пилот и цифры. Если команда из трёх человек, спикер берёт продуктовые вопросы.

Если оператора нет, спикер делает паузу на каждом переходе, кликает и только потом продолжает фразу.

## 2. Маршрут выступления

Время ориентировочное: текст короче прежнего, оставлен запас на переключение экранов и реакцию зала. Прогон с секундомером обязателен.

| Время     | Экран                       | Смысл, который должен понять зритель                                 |
| --------- | --------------------------- | -------------------------------------------------------------------- |
| 0:00–0:30 | Первый слайд / обзор        | Между идеей и проектом нужен понятный путь.                          |
| 0:30–1:05 | Команда EduQuest            | Пять шагов и сохранённая работа вместо пустой страницы.              |
| 1:05–1:30 | Координатор школы           | Взрослый видит, кто остановился, и помогает вернуться.               |
| 1:30–2:05 | Организатор → лига          | Балл даёт подтверждённая публикация; школа может вызвать другую.     |
| 2:05–2:20 | Лига / слайд механики роста | Одна школа запускает несколько команд и приглашает следующую.        |
| 2:20–2:45 | Финальный слайд             | Следующий шаг — небольшой пилот, а не обещание мгновенного масштаба. |
| до 3:00   | Финальный слайд             | Запас на клики и спокойную концовку.                                 |

## 3. Что говорить и куда нажимать

Сервис находок в начале — **выдуманный пример для объяснения**, не реальный кейс. EduQuest и остальные команды на экране — демо.

### 0:00 · Начало

**Экран:** «Идея есть. А что дальше?» или обзор продукта.

> Представьте команду школьников. Они хотят сделать сервис находок для своей школы: чтобы потерянная вещь быстрее находила владельца. Идея есть. Но что дальше — с чего начать, кого спросить, как оформить проект?
>
> Мы сделали Startify Sprint — недельный школьный спринт поверх AI Startify. Не ещё один конкурс презентаций. Понятный маршрут от знакомой проблемы к проекту, который можно показать.

### 0:30 · Команда

**Клики:** профиль → «Демо-команда» → EduQuest. Показать маршрут и заметки. Нажать «Следующий шаг», если ответ уже подготовлен на репетиции. Затем «Этап 5» → «Код вашей команды».

> Вот EduQuest. Вместо пустой страницы — пять шагов: выбрать проблему, поговорить с людьми, описать решение, подготовить питч и опубликовать паспорт в AI Startify.
>
> Рабочая тетрадь сохраняет результаты, а наставник помогает со следующим шагом. Сейчас подсказки шаблонные, модель SmallThinker не запущена — это прямо отмечено в интерфейсе.

Код показываем спокойно, без отдельной лекции про антифрод. Он понадобится в следующей фразе про проверку.

### 1:05 · Школа помогает команде

**Клики:** профиль → «Демо-координатор» → «Кому помочь сегодня» → команда без активности → «Напомнить» → подготовленный пресет → «Отправить».

> А это кабинет школы. Координатор видит, какая команда остановилась, и может отправить напоминание. Личные заметки участников ему не показываются.
>
> Идея простая: команда работает сама, но рядом есть взрослый, который помогает ей не потеряться.

### 1:30 · Результат проверяет человек

**Клики:** профиль → «Демо-организатор» → очередь → CampusLoop или GreenFuture. Показать код, отметить четыре доступных чекбокса, подтвердить публикацию. Затем открыть школьную лигу.

> Команда публикует проект в AI Startify и присылает ссылку сюда. Организатор проверяет паспорт, сверяет код команды и подтверждает публикацию. Только после этого проект попадает в лигу.
>
> Школа видит результат своих команд. Координатор может отправить другой школе ссылку-вызов: «А сколько проектов до публикации доведёте вы?»

**Оператору:** у демонстрационных заявок четыре пункта проверки. Пятый — наличие кода в паспорте — появляется у реальной заявки. Не искать его в демо. Если нужно пояснить: «Демо-ссылки учебные; у реальной заявки проверяющий дополнительно сверяет код в паспорте».

**Ссылка-вызов:** достаточно показать кнопку в лиге. Копирование не обязательно; оно не доказывает вирусный рост само по себе.

### 2:05 · Как это может распространяться

**Экран:** лига или простая схема «школа → команды → проекты → следующая школа».

> Так мы хотим расти: подключаем школу, запускаем несколько команд, а их результат становится поводом подключить следующую.
>
> Для нас успех — не регистрация, а подтверждённый проект.

### 2:20 · Концовка

**Экран:** «Сначала пилот. Потом масштаб.»

> Сейчас у нас рабочий прототип и учебные данные. Следующий шаг — пилот с пятью школами и тридцатью команд. Измерим, сколько команд доходят до публикации и где им нужна помощь. Масштабировать будем по результатам, а не по красивому прогнозу.
>
> AI Startify даёт инструменты для проекта. Startify Sprint помогает школьникам ими воспользоваться: вместе, по шагам и до результата.

После последней фразы остановиться. Не добавлять «ну, в целом это всё» и не начинать пересказывать функции ещё раз.

## 4. Что убрать из прежнего показа

- Долгий разбор воронки и всех процентов.
- «115×», количество модераторов и подробный бюджет из основной речи.
- Переключение всех ролей ради демонстрации каждого экрана.
- Отдельную остановку на EN, если времени мало.
- Рассказ о тестах, JSON и серверной архитектуре без вопроса жюри.

Всё это есть в документации и ответах: [PITCH.md](PITCH.md), [GROWTH_STRATEGY.md](GROWTH_STRATEGY.md), [DEADLINE_2026.md](DEADLINE_2026.md).

## 5. SmallThinker: одна понятная мысль

**AI помогает думать, но не делает работу за ученика и не решает, засчитать проект.**

Если спросили про модель:

> Адаптер подготовлен и проверен тестами. Сама SmallThinker здесь не запущена, поэтому сейчас вы видите шаблоны с честной меткой. Для реального включения нужен сервер с моделью, затем проверка ответов и задержки. Черновик применяется только по кнопке команды, а публикацию подтверждает человек.

Не обещать запуск за фиксированные 20 минут. Инструкция подключения — [SMALLTHINKER.md](SMALLTHINKER.md).

## 6. Перед выходом

- [ ] Приложение действительно открывается на демо-ноутбуке; `/api/health` отвечает.
- [ ] Демо сброшено **заранее**, не на глазах у жюри.
- [ ] Язык RU, масштаб удобен на проекторе, уведомления выключены.
- [ ] EduQuest открывается; нужный этап и код видны.
- [ ] У координатора есть команда для напоминания; пресет проверен.
- [ ] В очереди есть CampusLoop / GreenFuture; подтверждение отрепетировано.
- [ ] После подтверждения лига обновляется; ссылка-вызов на месте.
- [ ] есть локальные скриншоты команды, координатора, проверки и лиги.
- [ ] Текст проговорён вслух вместе с кликами, а не только прочитан глазами.
- [ ] Известно, сколько минут дали именно вашей команде. Если одна минута — использовать короткую версию из PITCH.md, не ускорять трёхминутную.

## 7. Если что-то пошло не так

**Не загружается приложение:** открыть скриншоты и продолжить тот же рассказ. Не чинить код на сцене.

**Не отправляется напоминание:** показать список «Кому помочь сегодня» и объяснить действие. Не повторять клик десять раз.

**Спросили про срок 10 000 проектов:** «Мы посчитали ограничения до 31 декабря. Без национального партнёра обещать этот результат было бы нечестно. Предлагаем сначала проверить механику на небольшом пилоте и масштабировать по измеренной конверсии».

**Спросили про реальные результаты:** «Пока это рабочий прототип с учебными данными. Подключённых школ и измеренной когорты ещё нет — это следующий этап».
